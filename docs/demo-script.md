# デモ台本（対比シナリオ）

5 分のデモで「KAWANAI が既存サービスと何が違うか」を見せるための台本。ポジショニングと比較表は [README](../README.md#競合比較ポジショニング) を参照。

数値はローカル環境（`npm run db:reset` の決定論的シード）で実際に計算した値。商品・ブランドはすべて架空。

## 準備

```bash
npx supabase start
npm run db:reset
npm run dev
```

デモ用アカウントのポーチ（手持ち）に 3 つだけ登録しておく。`/scan` のチェックリストから 1 タップで入る。

| 手持ち（ポーチ） | カテゴリ | 価格 |
| --- | --- | --- |
| DAILY+ デイリークッション 300 オークル | ファンデ | ¥1,980 |
| PRICO メルティリップ 03 テラコッタ | リップ | ¥980 |
| PRICO 9色アイパレット 01 ブラウン | アイシャドウ | ¥1,480 |

## 0. 導入（30 秒）

> 「コスメアプリは『何を買うか』を教えてくれます。KAWANAI は逆で、『買わなくていい』を成分と色の数値で証明します。」

比較表を 1 枚出して、LIPS / @cosme（クチコミで買う）、コスメ管理アプリ（記録するだけ）、Skinskool（成分だけ）、Findation（色だけ）に対して、KAWANAI は **手持ち在庫 × 色差 ΔE × 成分ベクトル** を 1 つの結論に統合していると言う。

## 1. 対比シナリオ：「評価は高い。でも、あなたはもう似た色を持っている」（90 秒）

**画面**：`/search` → `mode noir セラムファンデーション 300 オークル`（¥7,800）→ 商品ページ

- クチコミ系アプリでの見え方：口コミ 11 件（うち宣伝目的と判定した 5 件を除いた 6 件で ★3.8）の人気商品。ここで普通のアプリの結論は「買う」。
- KAWANAI の見え方：ページ上部に **「もう持っています」**（手持ちの DAILY+ デイリークッション 300 オークルとの被り）。

内部の数値（画面には出さず、`src/lib/wording.ts` で言葉に置き換えている）:

| 指標 | 値 | 画面の言葉 |
| --- | --- | --- |
| 色差 ΔE(CIEDE2000) | **1.60** | 「並べても違いは分かりにくい色です」 |
| 成分ベクトルの cosine 類似度 | **0.976** | 「中身はほとんど同じ処方です」 |
| 被りスコア `0.6*cos + 0.4*(1-ΔE/10)` | **0.921** | 手持ち突き合わせのしきい値 0.5 を大きく超える |
| 価格差 | **−¥5,820**（¥7,800 → ¥1,980） | 「同じ処方でこっちが安い」 |

> 「LIPS で高評価なのは本当です。ただ、あなたのポーチにある ¥1,980 のクッションと ΔE 1.6・成分の一致 0.98。塗った結果はほぼ同じです。だから ¥5,820 は払わなくていい。」

**キャプチャ**：商品ページの「使い心地とねだんを比べる」と、その下の被り判定（手持ち商品・色見本・−¥5,820）。

**言い添える一言**：安い方に寄せるだけのアプリにはしていない。使用感の軸ごとの差（`ComparePanel`）で高い方の良さも同じ大きさで出すので、「それでも高い方が欲しい」も選べる。

## 2. パレット重複率：「9 色のうち、何色が新しい？」（60 秒）

**画面**：`/products/35`（LUMINA デイリーアイパレット 01 ブラウンベージュ ¥6,800）の「手持ちで似た色が出せるか」

`find_palette_coverage`（ΔE ≦ 5 を「手持ちで再現できる」とみなす）の結果。カテゴリをまたいで探すので、テラコッタは手持ちのリップが一番近い色として出る：

| パレットの色 | 手持ちの一番近い色（記載のない行は PRICO 9色アイパレット 01 ブラウン の同名の色） | ΔE |
| --- | --- | --- |
| ベース | ベース | 3.64 |
| ミルクベージュ | ミルクベージュ | 4.79 |
| ライトブラウン | ライトブラウン | 2.24 |
| テラコッタ | PRICO メルティリップ 03 テラコッタ | 1.26 |
| ローズブラウン | ローズブラウン | 2.69 |
| ブリック | ブリック | 1.46 |
| ダークブラウン | ダークブラウン | 2.09 |
| シマーゴールド | シマーゴールド | 2.25 |
| プラム | プラム | 1.11 |

画面の表示は **「9 色中 9 色 は、持っているコスメでほぼ同じ色が作れます」**（重複率 100%）。

> 「パレットは『1 色でも新しければ買う』になりがちです。KAWANAI は 9 色すべてを手持ちと突き合わせて、¥6,800 で増える色は 0 色だと言えます。」

**キャプチャ**：「手持ちで似た色が出せるか」の一覧（パレットの色と手持ちの色が対で並ぶ部分）。

## 3. リップの被りと「安い代替」（45 秒）

**画面**：`/products/1`（LUMINA グロウリップスティック 03 テラコッタ ¥3,800）

- 手持ちの PRICO メルティリップ 03 テラコッタ（¥980）と ΔE **1.26**、成分 cosine **0.960**、スコア **0.926**。
- 逆向きの使い方として、手持ちが無い人には `find_cheaper_dupes` が「同じ処方でこっちが安い」を出す。

> 「同じ結論を、手持ちがある人には『買わなくていい』、無い人には『安い方で足りる』として出します。」

## 4. 写真から色を探す（30 秒）

**画面**：`/color` に画像を投げる → 主要色を抽出 → Lab に変換 → `find_by_color`

> 「SNS で見た色や、店頭で撮った 1 枚から入っても同じ判断につながります。撮影した色は照明でずれるので、言い切らずに近い順に出します。」

## 5. 締め（30 秒）

> 「手持ちを入力にして、色差と成分を数値で突き合わせ、結論を『買わなくていい』側に置く。ここは既存サービスが埋めていない空白地帯です。買い物を減らすほど、ユーザーの財布と在庫が軽くなります。」

## 数値の出どころ

| 数値 | 実装 |
| --- | --- |
| ΔE(CIEDE2000) | `lab_delta_e` / `products_min_delta_e`（`supabase/migrations/20260815000800_product_colors.sql`） |
| 成分 cosine 類似度 | pgvector `1 - (a <=> b)`。ベクトル生成は `20260815000400_ingredient_vector.sql` |
| 被りスコア | `dupe_score(ing_sim, delta_e) = 0.6 * cos + 0.4 * max(0, 1 - ΔE/10)` |
| パレット重複率 | `find_palette_coverage(p_product_id, p_max_delta => 5)` |
| 数値 → 日本語 | `src/lib/wording.ts` |
